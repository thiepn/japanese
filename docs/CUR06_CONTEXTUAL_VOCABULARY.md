# CUR-06 Japanese native source-bound contextual vocabulary

Implements a real learner-facing study path in the existing Japanese StudyPlayer, as an extension of the original CUR-05 source-grounded six-level Course catalog. No source content, lexeme IDs, canonical sentence text/translations, teacher-provided audio or external licensed Marugoto exercises are invented.

Each installed original lexeme with a public-exportable original registry source provides spelling, kana, recorded lexical gloss, attested original alternative forms, the original vocabulary lesson and linked native CourseUnit source Can-do. In **Contexts**, only StudyLesson pages appear. Japanese examples are shown exclusively where an installed original course-unit Sentence ID explicitly links to that unit, its installed Japanese text contains the exact lexeme spelling, and the sentence's original source is authorized. If none exists, the lesson says that no verified sentence is present. All actual source-owned multi-unit contexts appear, with a contrast of source Can-do purposes rather than fabricated word CEFR ratings. No review event or due timestamp is changed by reading.

In **Practice**, the same source-grounded sequence leads from explained spelling/reading/meaning contrasts into original-source-backed foils (two recorded real lexical alternatives), each carrying distinct corrective feedback, then independent typed kana and Japanese recall and optional independent Japanese writing. All new controlled and written prompts carry `cur06:true`, `nonAuthoritative:true`, `schedulerExcluded:true`, `independentCompetenceVerified:false` and original lexeme source attribution. Existing StudyPlayer persists ungraded skipped StudyEvents and original optional account-local drafts, and it does NOT call the FSRS scheduler for these new prompts. The existing original **Review selected due** / **All Japanese due** are the only CUR-05 graded review launches.

Practice supports truthful account/device-local resume and explicit restart using CUR-04's exact-step-and-content-fingerprint checkpoint implementation, prefixed `cur06-` to isolate it from original course unit positions. Restart does not delete earlier StudyEvents/FSRS history. Read-only Contexts do not create this pointer. No duplicate scheduler or new storage engine.
