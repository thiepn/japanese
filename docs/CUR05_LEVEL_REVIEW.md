# CUR-05 — Six-level source-linked vocabulary and native FSRS review

Existing canonical `CourseUnit.vocabularyIds` establishes a word's course-unit association, and the original course unit's level supplies only its **navigation grouping**; it is not a CEFR equivalence statement for an independent word. Words without that original source link are shown as **Unassigned**. A word may occur in several original levels and units; the selection de-duplicates the same FSRS prompt on a combined review session. Original lexeme/source IDs are checked against the installed public-exportable source registry. No vocabulary, translation, audio, rights or CEFR rating is fabricated.

The owner-fenced source projection reuses original `vocabularyMeaningPrompts`, `vocabularyApplicationPrompts`, FSRS `MemoryTrace.card.due` and original global due prompt pool, including private words and non-vocabulary prompts. Global due is a distinct value; filtered due is the unique source-backed vocabulary due subset. Per-level statistics may overlap across levels; the union never double-counts the same prompt. Vocabulary previews use only original `vocabularyLessons` (StudyLesson without prompt) and do not produce StudyEvents or move FSRS due dates. "Review selected due" passes the original due `StudyPrompt` objects unchanged to the original StudyPlayer/StudyEvent/FSRS writer. All Japanese due uses the unchanged original due queue.

The Japanese Course screen offers active level, all levels, and selective multi-level filtering, 18-item incremental word browsing, source/unit names, original writing/readings/meanings, truthful scheduled/due counts, original canonical unit navigation, and non-grading previews. C2 stays planned and does not gain invented content. Account changes fail closed through existing owner-fenced dashboard/StudyPlayer flows.

Unmerged PR #103's original 78 lesson IDs remain a non-publishing read-only mapping. Languages PR #30 content/player contracts remain unmodified, as do shared Languages PR #31, French PR #81, Chinese PR #96. No duplicate scheduler, learner-event storage, offline progress migration, publication, or deployment.

Native tests verify source, due dates, multi-level overlaps, invalid owner, malformed source, normal navigation; Chromium tests verify desktop/mobile browse, preview, per-unit links and C2. Full external account recovery and physical devices remain separate release qualification.
