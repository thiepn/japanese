# CUR-07 source-owned comparison and bounded local section recovery

The existing learner Course vocabulary browser now lets a learner explicitly select two distinct canonical `CourseUnit` IDs for any originally linked lexeme. Both selected unit IDs, original public-exportable sources and `CanDoDescriptor` references must pass existing verification. A selected-unit comparison renders the original Can-do statements and only genuinely source-linked installed Japanese sentences (where present). No new Japanese sentence, quotation, word-level CEFR mapping, proficiency grade or independent scheduler is generated. The original default compact Practice remains two-or-fewer units and the separate Contexts journey retains every original unit.

An explicit comparison uses the original `StudyPlayer`, native `cur06` unscored question IDs and unchanged original `vocabularyMeaningPrompts`/FSRS. The source pair has its own navigation-only `cur07-<word>-<firstUnit>-<secondUnit>` key. It does not overwrite legacy default `cur06-<word>` checkpoints, original course unit pointers, or immutable StudyEvents.

For repeated content/source revisions, CUR-07 adds a **device-local** bounded four-generation navigational history per Account owner and exact practice namespace. A receipt contains only step ID, per-step source content fingerprint, whole-session change detector, ordinal and timestamp. History never stores learner answers, accepted choices, grades, original source text or the original writing draft. On a changed queue it shows historical entries as either **unchanged section recoverable** or **changed/removed section blocked**. Restoration is an explicit action and requires that the original section ID exists uniquely in the new queue and that its actual source object has the same fingerprint; its new ordinal is recomputed, and only then does the original CUR-04 source-validated current checkpoint get updated. This is a local change detector and ordinary localStorage, **not authenticated source bytes, encrypted custody, atomic cross-tab CAS, cloud backup or tamper-resistant audit**. Storage failures/invalid records fail closed; older snapshots are pruned. Full current session rechecks before the native player opens.

Future CUR-07 app integration must not treat this as authorizing a different content version without independent source/pedagogical review. Unmerged PR #103/PR #30 source and rights boundaries remain unchanged. Release remains NO_GO pending independent source, physical-device and Account-recovery qualification.
