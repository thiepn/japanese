# CUR-04 — Flexible Japanese course entry, source-validated recovery, and source reconciliation

## Native learner experience
Six independent course levels remain navigable without prerequisite gates. Every available canonical course unit offers **Open/Resume** and an explicit **Restart** from its first section. Restart only resets the local navigational pointer; immutable StudyEvents, original FSRS traces, Account association, rights/provenance and all existing lesson identities remain unchanged. Previously answered prompts can be viewed again through the native player; restarting is not evidence erasure. The original app also retains the original delayed review scheduling.

Optional self-report ("new" through "very advanced") produces a **navigation-only recommendation** from currently source-backed course units. It does not diagnose CEFR level, certify a score, grant mastery or prevent opening another level. If the requested level has no real units (C2), it falls back to the highest available lower level and explicitly says so. No self-report data is persisted.

## Stronger exact-session recovery
CUR-03 stored an ID-only local pointer (v1). CUR-04 uses a versioned v2 pointer with a bounded content fingerprint computed over the actual ordered native StudyStep objects, covering original content provenance, exact prompts, feedback, accepted answers, and source versions. It stores only unit and step IDs, ordinal, timestamp, and the short fingerprint—not learner answers or instructional source text. Different account, altered content, corrupt receipt, duplicate steps or another unit fails closed. **Existing v1 navigation pointers are deliberately not trusted for resume when content could have changed**; native StudyEvents and FSRS are unaffected. Device-local checkpointing is not a backup, does not sync across devices, and is not an Account migration. Restart records step 0 only after the requested native source session has been loaded and checked; disabled storage is acknowledged in the player.

## Explicit unmerged source reconciliation
Japanese PR #103 (`feature/course-first-a1-c0-c1`, SHA `1e3667ebdcb0cd50491c126b948c11f47414decb`) defines original `cf-a1-NN-MM` lesson IDs, its own `validateAuthoredCourse` editorial/rights gates and existing canonical `a1-unit-NN` source anchors. Its 78 lesson IDs, controlled choices, independent drafts and native E02 capstones **remain draft-owned and are not included here**. CUR-04 does not claim that #103 lessons are live, released or incorporated; installed `lesson-*` canonical items and newly authored `cur03-*` context lenses remain distinct. Their objectives can overlap pedagogically, so future integration must compare source, original IDs, actual exercises and licensing before any replacement or adoption; copying these 78 lessons would duplicate learner-state and rights responsibility. The original #103 authoring uses a canonical can-do map, scene lookup, source registry and no invented audio/proficiency claims.

Languages PR #30 (`feature/phase01-platform-ownership-20261022`, inspected SHA `141f74d3a1a942241d6c81e19486ae8741784b61`) exports a versioned, rights-gated `LessonV1/ExerciseV1/LanguagePluginV1` typed contract with `mayScheduleReview:false` and `mayAssertProficiency:false`. This Japanese change does not duplicate it or transfer authority from the native StudyPlayer, StudyEvent writer, FSRS or Account-scoped IndexedDB. The source-linked external lesson mapping remains **blocked** until #103's validated materials and the evolving #30 schema are reconciled at exact heads, rights/metadata are approved and native events are preserved. Shared Languages CUR-01 PR #31, French PR #81 and Chinese PR #96 remain unchanged.

## Publication and evidence
Original prompt IDs, user records and rights remain authoritative. All CUR-03/04 contextual checks are recorded as non-authoritative and excluded from FSRS/proficiency. Three additional original A1 teaching situations about `に` movement destinations, `好きが` preferences and `あります/います` existence were added only when the installed unit includes their canonical grammar source anchor. No licensed Marugoto exercise or audio was copied. No promotion, deployment or native production writes are authorized.

Tests require TypeScript, source-preserving Vitest (including forged checkpoints, content drift, disabled storage, self-report, namespace separation), original canonical course regression, production build and real desktop/compact-mobile Chromium for restart/resume, independent B1 selection, planned C2 and optional recommendations.
