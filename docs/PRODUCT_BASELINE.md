# Product Baseline

Japanese is a local-first, source-aware learning environment that maintains one unified model of the learner's Japanese knowledge and uses that model to coordinate structured learning, spaced retrieval, comprehensible input and productive practice.

## Primary surfaces

1. Today
2. Learn
3. Immerse
4. Library
5. Progress

## Non-goals

The product is not a Duolingo clone, prettier Anki, WaniKani clone, Bunpro clone, AI-chat wrapper, generic notes app, social network, RPG, or PDF-to-flashcards generator.

## North-star objective

Durable, transferable Japanese gained per minute of learner effort.
