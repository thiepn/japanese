# Japanese

A unified, local-first Japanese learning system in the THIEPN ecosystem.

## Product contract

Course, reviews, reading, listening, writing, speaking, authentic-input mining and AI coaching all emit evidence into the same learner state rather than maintaining independent progress systems.

Primary product surfaces: **Today · Learn · Immerse · Library · Progress**.

## Current phase

**P16 — C1 Research Quality, Bibliography, Human Review & Specialist Tracks is implemented.**

P16 deepens the P15 authentic C1 working environment without introducing another mastery layer:

- structured bibliography metadata for the exact P15 sources the learner actually used;
- Japanese research-note, APA-like and compact citation rendering from one canonical record;
- learner-supplied source excerpts split explicitly between private-reference material and redistributable/licensed material;
- no automatic scraping or promotion of arbitrary external pages into the public content package;
- reviewer packets that bind the exact P15 thesis, first draft, delayed revision, defenses, source map and bibliography;
- external human review across argument control, source use, language precision and register control;
- human review remains artifact-bound qualitative evidence and cannot silently update FSRS mastery or award a CEFR result;
- specialist tracks that connect the learner's real sources, mined terminology and C1 projects around actual interests;
- all P16 state remains derived from the existing StudyEvent stream.

P15 remains the prerequisite environment: source registration, source evaluation, specialist terminology, source maps, multi-day writing, hidden-pressure defense and delayed revision stay authoritative.

The evidence boundary remains strict. Citation formatting does not prove interpretation quality, a learner-pasted excerpt is not redistributable without an explicit license, human scores are not accredited CEFR judgments, and specialist tracks are not subject-matter certification.

P11 remains an independent release-evidence track and can still report `HOLD_B2_RELEASE_CANDIDATE` until the required real external productive-language review is admitted.

See `docs/P16_ACCEPTANCE.md`, `docs/P15_ACCEPTANCE.md` and `docs/ROADMAP.md`.

The next useful work should move toward a C1→C2 precision bridge and more natural real-time interaction: stylistic precision, sustained specialist discourse, fresh-source refresh tasks and a stronger live voice/reviewer loop where the underlying speech stack can support the evidence claim.
