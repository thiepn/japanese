# Japanese

A unified, local-first Japanese learning system in the THIEPN ecosystem.

## Product contract

Course, reviews, reading, listening, writing, speaking, authentic-input mining and AI coaching all emit evidence into the same learner state rather than maintaining independent progress systems.

Primary product surfaces: **Today · Learn · Immerse · Library · Progress**.

## Current phase

**P14 — C1 Long-Form Autonomy, Domain Specialization & Cross-Session Productive Reliability is implemented.**

P14 turns the C1 system into a longitudinal learning path:

- 5 long-form autonomy missions across research, governance, technology, media and cross-domain transfer;
- each mission spans C1 reading, audited native sources, multi-source synthesis, hidden-future interaction, production, delayed transfer and reflection;
- delayed transfer requires structurally successful evidence on two days separated by 20+ hours;
- domain specialization status is derived from StudyEvents rather than stored as a new mastery badge;
- C1 productive tasks and synthesis packs gain cross-session reliability tracking;
- spontaneous interaction reliability is measured separately;
- Progress now includes a dedicated longitudinal C1 portfolio;
- C1 portfolio export is available in JSON and Markdown;
- mission next steps route into the existing Reader, P13 source lab, Study Player and C1 AI coach.

The evidence boundary is unchanged: internal structural success is not complete semantic grading, repeated internal reliability is not external certification, speech recognition is not acoustic scoring, native playback is not automatic comprehension mastery and AI feedback does not become durable learner truth.

P11 remains an independent release-evidence track and can still report `HOLD_B2_RELEASE_CANDIDATE` until the real external productive-language review is admitted.

See `docs/P14_ACCEPTANCE.md`, `docs/P13_ACCEPTANCE.md` and `docs/ROADMAP.md`.

The next phase should deepen the real C1 environment: broader native genres, source evaluation/citation, multi-day advanced writing projects and richer specialist-domain language.
