# Japanese

A unified, local-first Japanese learning system in the THIEPN ecosystem.

## Product contract

Course, reviews, reading, listening, writing, authentic-input mining and future AI features must all emit evidence into the same learner state rather than maintaining independent progress systems.

Primary product surfaces: **Today · Learn · Immerse · Library · Progress**.

## Current phase

**P4 — A2 Expansion, Native Audio & Authentic-Input Pipeline is implemented.**

The app now provides one connected Foundation → A1 → A2 → immersion system:

- reusable Study Player for lessons, reviews, listening, grammar, conjugation, sentences and assessments;
- complete hiragana/katakana Foundation with multi-skill evidence;
- **274 canonical lexemes** with meanings, readings, source provenance and native audio where verified;
- **66 grammar concepts**, including 29 A2 concepts with canonical contextual practice;
- **161 linked sentences** and **32 capability-centered course units** in one course graph;
- delayed unit checks and the existing five-area A1 milestone;
- **16 canonical graded texts** spanning A1 through A2;
- graph-aware reading with optional reading hints, translations, contextual lookup and grammar support;
- **108 additional verified native vocabulary recordings** from the pinned Tofugu/WaniKani CC BY-SA source;
- explicit audio license, attribution and native-speaker metadata;
- recorded connected audio when a licensed asset is actually attached, with device Japanese speech synthesis as a labeled fallback;
- private paste / TXT / Markdown / SRT / VTT ingestion;
- a hybrid authentic-text analyzer using canonical forms, generated inflections, A2 surface patterns and browser Japanese segmentation;
- lexical known-word ratio, unresolved-form count and comfortable/stretch/hard estimates for imported material;
- contextual mining of canonical words plus learner-defined private unknown words;
- private mined vocabulary returning to the normal Today queue, learner projections and FSRS scheduling;
- a license-aware Tatoeba sentence import route that admits audio only when the individual recording declares a reusable license;
- persistent account-scoped learner data and private imports without copying learner material into the public content package.

Current core content package: **v0.6.0 / schema 7** with 274 lexemes, 66 grammar concepts, 161 sentences, 32 Can-do descriptors, 32 structured units, 16 graded texts and 147 canonical audio assets.

P4 deliberately does **not** claim perfect unrestricted Japanese morphology, automatic dictionary-quality definitions for unknown imported words, or native recordings for every connected text. Private unknown forms require a learner-supplied meaning before review. Speech synthesis remains labeled as fallback rather than native audio.

The next development phase is **P5 — B1 Expansion, Productive Language & Adaptive Immersion**.
