# Japanese

A unified, local-first Japanese learning system in the THIEPN ecosystem.

## Product contract

Course, reviews, reading, listening, writing, speaking, authentic-input mining and AI coaching all emit evidence into the same learner state rather than maintaining independent progress systems.

Primary product surfaces: **Today · Learn · Immerse · Library · Progress**.

## Current phase

**P15 — Authentic C1 Environment, Source Evaluation, Multi-Day Writing & Live Defense is implemented.**

P15 makes advanced Japanese materially less course-like and more like actually working in Japanese:

- 12 real Japanese source portals covering government, statistics, research, law, policy and institutional communication;
- exact-source registration with HTTPS/host validation;
- source-role-aware evaluation of claim, evidence, limitation and communicative purpose;
- source-grounded specialist vocabulary flowing into the existing private-vocabulary review path;
- 5 substantial multi-day writing projects requiring source, genre and publisher diversity;
- stable `[S#]` source traceability across first draft and delayed revision;
- 16 hidden pressure types for unpredictable argument defense;
- distinct post-draft defense requirements;
- 20+ hour delayed reconstruction rather than same-session polishing;
- C1 portfolio schema v2 with source/evaluation/project/defense evidence.

P15 deliberately does not copy arbitrary external documents into the canonical public content package. External material remains linked in its original context; the app stores source identity plus the learner's own evaluation, terminology, drafts and defense responses.

The evidence boundary remains strict: learner source evaluation is not independent fact verification, citation-marker presence is not semantic writing quality, browser speech recognition is not acoustic scoring, typed defense is a speaking-task proxy, and internal project completion is not CEFR certification.

P11 remains an independent release-evidence track and can still report `HOLD_B2_RELEASE_CANDIDATE` until the real external productive-language review is admitted.

See `docs/P15_ACCEPTANCE.md`, `docs/P14_ACCEPTANCE.md` and `docs/ROADMAP.md`.

The next useful work is quality/depth rather than another progress layer: stronger source ingestion where licensing permits, bibliography support, human review of selected C1 projects, richer personal specialist tracks and a later C1→C2 precision bridge.
