# Japanese

A unified, local-first Japanese learning system in the THIEPN ecosystem.

## Product contract

Course, reviews, reading, listening, writing, speaking, authentic-input mining and AI coaching all emit evidence into the same learner state rather than maintaining independent progress systems.

Primary product surfaces: **Today · Learn · Immerse · Library · Progress**.

## Current phase

**P13 — C1 Native-Source Depth, Multi-Source Synthesis & Spontaneous Interaction is implemented.**

P13 deepens the C1 system with three forms of real-world pressure:

- 8 repository-verified connected native sources;
- 4 native-source listening/synthesis sets across speakers, register and source-rate conditions;
- 6 multi-source C1 synthesis packs using the canonical P12 texts;
- C1 coach support with explicit spontaneous-interaction mode;
- 5 hidden-future C1 scenario chains with methodological, institutional, rhetorical and implementation pressure;
- source playback, source notes, synthesis and interaction evidence recorded through the existing StudyEvent architecture;
- no separate P13 mastery store.

P13 keeps the same evidence boundaries: native-source playback is not automatic comprehension mastery, structural synthesis checks are not semantic grading, AI feedback is advisory, browser speech recognition is not acoustic scoring and internal C1 work is not CEFR certification.

P11 remains an independent release-evidence track and can still report `HOLD_B2_RELEASE_CANDIDATE` until the real external productive-language review is admitted.

See `docs/P13_ACCEPTANCE.md`, `docs/P12_ACCEPTANCE.md` and `docs/ROADMAP.md`.

The next development phase should deepen long-form C1 autonomy, domain specialization, broader native text/audio exposure and productive reliability across days.
